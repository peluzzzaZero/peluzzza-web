Checklist rápido (path chooser)

  1. ¿Parado en garaje privado y quieres conservarlo? → Path A: baja temporal sede / miDGT + tasa 4.1.
  2. ¿Se acerca el fin del año de baja? → Path B: prórroga (2 meses antes) o aceptas alta automática.
  3. ¿Quieres volver a circular? → Path C: alta desde baja temporal + ITV favorable + seguro.
  4. ¿Robo / sustracción? → Path D: denuncia FFCCSE (ellos comunican; sin tasa).
  5. ¿Agrícola? → Path E: primero ROMA (CCAA), luego DGT; baja indefinida sin prórroga anual.
  6. ¿VMP / patinete? → Path F: no hay baja temporal; solo definitiva tras fin de vida útil.
  7. ¿Desguace / export? → Path G: baja definitiva (otro trámite; no confundir).

Bloqueos habituales: precinto, notificación de venta, duplicado por reforma, placa verde / titular fallecido. Regularízalos antes de pedir la baja.

Tasa y canales (cifras sede)

  • Tasa 4.1: 8,67 € por baja temporal o por cada prórroga (sede 2026-09-26). Gratuita por sustracción.
  • Online: certificado digital, DNIe o Cl@ve en sede.
  • App: miDGT → Mis trámites → Iniciar baja temporal de vehículo.
  • Presencial: Jefatura con cita (web o 060); solo particulares. Empresas → electrónico.
  • Tras la baja: conserva el justificante para paralizar la póliza con tu aseguradora.

Fuente tasa: sede — Baja temporal y prórroga. La página marketing a veces muestra “XX,XX€”; usamos la cifra de la sede. Re-fetch antes de update.
